# Photo Pick

카메라 사진을 별로·좋음·아주 좋음으로 평가하고, 카드 또는 앨범에서 골라보는 웹 프로토타입입니다.

[공개 사이트 열기](https://photo-pick-camera.heundeun.chatgpt.site)

## 사용

예시 사진으로 체험하거나 JPEG 사진 파일·폴더를 선택합니다. 선택한 사진은 브라우저에서 읽으며 서버로 업로드하지 않습니다. 평가 결과는 같은 브라우저에서 복원할 수 있습니다. 휴대폰 사진함 저장은 아직 체험 기능입니다.

## GitHub Pages

저장소 Settings → Pages → Source를 GitHub Actions로 설정합니다. main 브랜치에 변경을 올리면 포함된 워크플로가 사이트를 배포합니다.

빌드나 패키지 설치가 필요 없는 정적 HTML 앱입니다. index.html과 assets를 함께 배포해야 합니다.
