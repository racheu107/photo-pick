# 핀치줌 위치 수정 — 2026-10-10

0.2.19 / versionCode 22 / 별도 디자인 앱. 이전 APK와 소스 ZIP, 운영 소스61개 및 운영 APK를 해시로 보존 확인했습니다.

원인: 첫 손가락으로 설정한 사진 넘기기 회전 축이 두 손가락 확대에 남아 있었습니다. 줌 계산은 카드 중심을 사용하면서 실제 변환은 상단/하단 축을 사용해 확대 초점이 벗어났습니다. 재핀치 시 transform을 비우는 것도 위치 점프를 만들었습니다.

수정: 두 손가락이 닿으면 변환 축을 사진 중앙으로 되돌리고 실제 사진 중심을 고정 기준으로 저장합니다. 이전 확대/이동 값을 유지하며 두 손가락의 중점 이동과 거리 변화에 맞춰 변환합니다. 이동 한계도 카드 대신 실제 사진 크기로 계산합니다. 모든 손가락을 떼면 원래 사진 크기로 복귀하는 기존 동작은 유지합니다.

검증: 수정 전 세로 사진 위쪽 핀치에서 초점274.5px 이동 및 재핀치 transform 소실을 재현했습니다. 수정 후 가로/세로/정사각형 x 위/아래6개 실제 핸들러 검사에서 초점오차1px미만, 2배확대, 재핀치 위치유지, 평가/사진번호 불변 통과. 브라우저 터치 주입2개는 포인터 캡처·확대·두손가락 이동·전체 해제 확인. 기존 사진끌기/방향/평가/배경블러/모션감소 회귀검사 통과. Android assembleDebug 및 lintDebug 성공, 동일서명 및 APK웹자산 소스일치 확인. 실제 Android 기기 검증은 미실행입니다.
