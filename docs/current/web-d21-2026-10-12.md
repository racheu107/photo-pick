# 웹 d21 적용 — 2026-10-12

PC2에서 사용량 제한으로 중단된 웹 적용을 PC1에서 이어서 검증했다. 공개 웹 소스는 github-upload이며 웹 버전은 0.2.27 d21이다.

## 적용 범위

- 분리형 평가 버튼, 하트와 반짝임 아이콘, 매우 좋음 명칭 통일.
- 평가 후 다음 미평가 사진으로 이동, 터치 확대 유지와 초기화.
- 뒤 사진 블러 스택, 좌우 회전, 드래그 축소와 버튼 연결 모션.
- 시작 화면과 최초 평가 안내. 브라우저 파일 선택·촬영일 분류·원본 다운로드 연결.
- Android 프로젝트 및 APK는 변경하지 않았다. 최종 N장 선택·A/B 비교는 d15에서 제거한 현재 상태를 유지한다.
- 앱 재실행 시 안내 1회, 최초 좌우 넘김 안내 X 표시는 별도 후속 작업이다.

## 검증

design-preview/tests/web-d21.cjs를 PC1에서 실행해 통과했다. 시작 화면, 안내 중 평가 차단, 평가 자동 이동, 두 손가락 확대 유지, 회전·축소 드래그, 실제 JPEG 파일 불러오기, 예시 PNG 다운로드, 원본 JPEG 바이트 일치, ZIP 내 원본 두 장 바이트 일치, 320px·430px 화면, 1440px PC iframe을 확인했다. JavaScript 예외와 HTTP 오류가 없었다.

검증 캡처 및 checks.json은 design-preview/verification/web-d21에 있다. 실제 휴대폰·Safari 검증은 수행하지 않았다.

## 배포

main 푸시 시 .github/workflows/pages.yml이 공개 웹을 갱신한다. Android 빌드는 Android 경로 변경이 있을 때만 실행된다. 배포 완료 여부는 GitHub Actions 및 공개 웹 재검증으로 확인한다.
