# 원본 0.2.7과 디자인 0.2.20 d14 비교 점검

점검일: 2026-10-12. 원본 기준은 `android-release/PhotoPick-0.2.7-debug.apk`와 `backups/0.2.7-before-design-2026-10-09/source/android-app`. 비교 기준은 `design-preview/releases/PhotoPick-DesignPreview-0.2.20-d14.apk`와 `design-preview/source/android-app`이다. 기획 문서만 비교하지 않고 실제 APK 내부 자산·소스·패키지·서명 및 브라우저 평가 동작을 확인했다. 기능 코드는 변경하지 않았다.

## 먼저 바로잡을 설치 설명

원본 0.2.7은 `com.photopick.app`, 디자인 0.2.20은 `com.photopick.app.designpreview`로 서로 다른 앱이다. 이번 디자인 버전은 원본을 덮어쓰는 업데이트가 아니며 두 앱을 나란히 설치할 수 있다. 원본 0.2.7을 삭제할 필요가 없다. 평가·선택 기록 및 폴더 권한도 자동으로 옮겨지지 않는다.

이 PC에 남아 있는 원본 0.2.7 APK와 새 d14 APK 인증서는 동일한 `1d2b4523d601265d95c93690680cef2698410795b6f81bf018f793352f67fb31`이다. 이전 디자인 0.2.19 APK 인증서는 `dd444f64830aba19a0f2697b9443f8229300ba06e45b5d8e7572d9ff0b2d2de6`이다. 따라서 알려진 서명 충돌은 이전 디자인 앱과 새 디자인 앱 사이이다. 사용자의 실제 설치 실패 화면은 확보하지 않아 다른 설치 실패 요인을 확정하지 않는다.

## 동작 확인

두 실제 APK에서 www 자산을 추출하여 브라우저에서 실행했다. 원본에는 최신 isPhotoMotionBusy 검사 API가 없어 기존 모션 완료 후 동작을 검사했다.

- 원본 첫 사진 best 평가: 첫 사진 best, 현재 위치 두 번째로 이동.
- 최신 첫 사진 best 평가: 첫 사진 best, 현재 위치 유지, 좋음·매우 좋음 표시 활성.
- 동일 best 재탭: 원본 best 유지 및 다음 이동, 최신 keep으로 변경 및 위치 유지.
- 원본 되돌리기: 이전 평가 스냅샷 복원. 최신 초기화: 현재 첫 사진 평가 제거, 다른 두 번째 사진 keep 유지.
- 원본 평가 결과: 베스트샷 버튼 없음. 최신: 버튼 있음, 다운로드 대상 조회 정상.
- 실제 기기에서 SD 읽기·갤러리 저장·햅틱·성능을 두 버전으로 재비교하지는 않았다. 코드 동일을 실제 기기 전체 회귀 통과로 표현하지 않는다.

## 보존·패키징 확인

- 원본 백업의 명세 대상 소스 61개 해시 모두 일치. 원본 보존 확인.
- 원본 APK 웹 자산 16개가 원본 백업과 일치.
- 최신 APK 웹 자산 23개가 현재 Android 소스와 일치.
- Android 소스 범위: 원본 33파일, 최신 40파일. 추가 7개, 변경 8개, 동일 25개, 삭제 0개.
- 추가 자산은 베스트샷 JS/CSS, 오프닝 JS/CSS/이미지, 디자인 CSS와 재질 메뉴 JS다.
- 변경 파일은 앱 버전·패키지, manifest 앱 이름, review-ui.js, ui-motion.js, index.html, AppUpdater.java, MainActivity.java, 앱 아이콘이다.

## 검토할 사용성 변화

평가 버튼 자동 이동이 없어져 버튼만 쓰는 사용자에게 추가 넘김이 필요하다. 대신 등급을 바꾸다 사진이 넘어가는 문제는 줄일 수 있다. 어느 쪽이 편한지는 실제 사용으로 확인해야 한다.

되돌리기 아이콘의 실제 기능은 직전 작업 복원이 아니라 현재 평가 초기화다. 아이콘만 보고 원본 Undo를 기대하면 오해할 수 있다. 아이콘 중심 버튼도 원본보다 처음 이해하는 데 설명이 필요할 수 있다.

원본 확대 보기에서는 모든 손가락을 떼면 원복하는 동작을 유지한다. 새 A/B 비교는 확대를 유지하며 별도 초기화를 제공하므로 두 화면의 확대 규칙은 다르다.

최신 구현과 공개 배포는 구분한다. d14는 로컬 APK이며 공개된 디자인 릴리스는 여전히 0.2.19다. 로컬 최신 파일을 설치한 것인지, 원본 앱과 디자인 앱 중 어느 아이콘을 실행했는지 확인이 필요하다.
