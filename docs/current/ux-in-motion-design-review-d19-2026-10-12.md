# UX in Motion 스타일 적용 난이도·디자인 검토

검토 기준: 0.2.25 d19 소스. 모션 디자인·비주얼 디자인 에이전트가 각각 검토. 앱 코드와 APK 변경 없음.

| 요소 | 현재 구현 | 추가 난이도 | 권장 범위 |
|---|---|---|---|
| 버튼 눌림과 복귀 | 아이콘 크기 반응과 공통 눌림 스타일 존재 | 낮음 | 눌린 선택의 내부 면/아이콘만 2~3% 축소, 터치 영역 고정 |
| 사진 흡수와 버튼 반응 연결 | 실제 등급 버튼으로 190ms 흡수, 출발 시 테두리 강조 | 낮음~중간 | 흡수 마지막 구간에 복귀·강조를 맞춤 |
| 뒤 카드 공급과 앞자리 정착 | 첫 뒤 카드 -10→-3px 이동, 퇴장 후 90ms 정착 | 중간 | 현재 진행률을 이어서 크기·위치·구도 전환 연결 |
| 블러로 앞/뒤 구분 | 뒤 2/3/4px 유지, 새 앞 사진 2→0px | 낮음 | 기존 규칙 유지, 앞자리 정착과 선명해지는 시점 일치 |

## 디자인팀 권장

1. 버튼·사진 흡수 연결을 먼저 다듬음. X·하트 공용 캡슐 전체를 축소하면 두 선택이 함께 눌린 것처럼 보이므로 선택한 부분만 반응. 매우좋음도 같은 강도. 바운스 없이 복귀.
2. 다음 카드 중 첫 카드만 조금 내려오게 함. 뒤 카드들의 동시 출렁임은 추가하지 않음. 대기 카드 블러 계속 유지.
3. 밝은 하늘·야경·피부색 사진이 버튼 뒤로 들어갈 때 아이콘 대비 확인. 금빛은 매우좋음의 짧은 국소 강조로 제한.

## 구현 시 확인할 점

- 기존 버튼 강조는 흡수 시작 시 재생하고 다음 화면에서 버튼 요소가 교체됨. 250ms 강조가 190ms 흡수 종료 전에 잘릴 수 있어 하나의 시간축으로 관리해야 함.
- 도착 반응을 기존 흡수 시간에 겹쳐 넣고 전체 평가 시간을 늘리지 않음. 다음 사진 로딩이 길어질 때 눌림 상태를 계속 유지하지 않음.
- 뒤 이미지 cover에서 앞 이미지 contain으로 구도가 바뀜. 블러를 줄이는 것만으로 구도 점프가 해결되지 않으므로 전환 보완은 중간 난이도.
- 누른 뒤 바깥으로 이동·입력 취소·화면 이탈 시 효과와 임시 상태 정리. 다음 사진에는 그 사진의 저장된 평가만 표시.
- 확대된 자세에서 평가 흡수를 이어가고 다음 사진은 전체 보기. 움직임 감소 설정 존중.
- 왼쪽 원형은 현재 사진 평가 초기화. 이전 사진이 되감겨 돌아오는 효과는 기능 의미와 맞지 않아 제외.

[UX in Motion Manifesto](https://medium.com/ux-in-motion/creating-usability-with-motion-the-ux-in-motion-manifesto-a87a4584ddc)의 Parenting·연속성·Obscuration을 현재 앱에 해석한 제안. 제시한 시간·크기는 디자인 후보이며 사용자 검증 결과가 아님.

권장 순서: 버튼·흡수 연결 → 뒤 카드 공급·앞 정착 연결 → 사진 밝기별 가독성 확인.
