# Photo Pick 추가 기능 검토 — 2026-10-12

사용자 요청에 따라 개발자·기획자·가상 사용자 담당 에이전트 3명이 검토했다. 가상 사용자 담당은 여행 초보, 가족·아이 연사 사용자, 음식·카페 SNS 사용자, 대량 SD 사진 취미 사용자 네 상황을 가정했다. 실제 인터뷰·설문·사용 시간 측정 결과가 아니며 아래 효용과 우선순위는 검증할 가설이다. 기능 코드는 변경하지 않았다.

## 추천 방향

현재의 불러오기 → 평가 → 베스트샷 N장 → A/B 비교 → 원본 복사 흐름에, 후보 찾기와 선택 이유를 기억하는 기능을 추가한다. 사진 관리 전체나 편집기로 범위를 넓히기보다 태그·메모·필터·선택 세트를 연결한다.

## 자동 인물·풍경·음식 태그

구현 가능하며 온디바이스 모델로 시작할 수 있다. ML Kit 기본 이미지 라벨링 모델은 400개 이상의 일반 라벨을 제공하지만 앱의 인물·풍경·음식 범주와 일대일로 대응하지 않는다. 제품 범주로 매핑하고 실제 사진으로 누락·오분류를 검증해야 한다.

- 사람과 음식이 함께 나온 사진에는 두 태그를 모두 허용한다.
- 확신이 낮으면 미분류로 남기고 사용자가 추가·제거할 수 있게 한다.
- 사용자 수정 태그는 재분석으로 덮어쓰지 않는다.
- 분석이 끝나지 않아도 평가와 선택을 계속할 수 있게 한다.
- 후보 목록에서 날짜·등급·태그를 함께 필터링한다. 필터 밖의 최종 선택도 유지하고 전체 선택 수를 보여준다.
- 자동 분류로 등급·최종 선택을 바꾸거나 사진을 삭제하지 않는다.
- ‘사람 포함’ 검출과 ‘누구인지 식별’은 다른 기능이다. 이름별 얼굴 앨범은 초기 범위에서 제외한다.

참고: [ML Kit 이미지 라벨링](https://developers.google.com/ml-kit/vision/image-labeling), [Android 적용 방식](https://developers.google.com/ml-kit/vision/image-labeling/android), [얼굴 검출과 개인 식별의 구분](https://developers.google.com/ml-kit/vision/face-detection).

## 메모와 파일 메타데이터

앱 안의 메모를 기본으로 한다. 태그와 함께 검색하며 SD 원본은 수정하지 않는다. 앱 삭제·기기 변경 시 기록을 보존할 수 있도록 내보내기·복원과 사진 식별 방식도 함께 설계한다.

JPEG EXIF의 UserComment 같은 필드에 메모를 쓰는 기술은 가능하지만, 현재 앱은 SD에 읽기 권한만 요청하고 저장 시 원본 JPEG를 그대로 복사한다. 원본에 직접 쓰는 기능은 권한과 원본 보존 정책을 바꾸는 작업이다. 다른 갤러리·PC 프로그램에서 메모가 보이는지도 별도 확인해야 한다.

메타데이터 기록이 필요하다면 다운로드 시 ‘메모 포함 사본’ 옵션을 후속으로 제공한다. 메모를 포함한 파일은 원본과 바이트가 달라지므로 ‘원본 그대로 저장’과 구분한다. JSON/CSV 기록은 별도 파일이며 사진 자체에 메모를 넣는 것과도 구분한다.

참고: [AndroidX ExifInterface](https://developer.android.com/reference/androidx/exifinterface/media/ExifInterface).

## 관점별 우선순위

- 개발자: 태그·메모·필터·백업 기반 → 자동 태그 → 유사 묶기 → 품질 의심 → 사본 EXIF 기록. 데이터 이동성과 분석 성능을 먼저 설계.
- 기획자: 최종 N장 선택에 직접 연결되는 태그·메모·다시 보기, 이후 목적별 세트와 구성 요약.
- 여행 가상 사용자: 인물·풍경·음식 필터와 날짜/장면별 구성 확인. 전체 N장만 맞추면 장소가 빠질 수 있다는 가설.
- 가족 연사 가상 사용자: 유사 묶기·A/B 비교·보류. 흐리거나 눈 감은 사진도 의미가 있을 수 있어 자동 탈락은 원하지 않을 수 있음.
- 음식·카페 가상 사용자: 음식 태그·방향 필터·게시 후보 세트·가게 이름 메모.
- 대량 SD 가상 사용자: 필터 조합·백그라운드 분석·캐시·기록 내보내기. 전체 분석을 기다리게 하지 않기.

## 단계 제안

1. 태그·메모·다시 보기와 필터 기반, 기록 내보내기/복원 설계. 등급과 독립 상태로 관리.
2. 온디바이스 자동 태그 제안과 수정, 선택 구성 요약, 목적별 세트.
3. 유사 컷 묶기와 A/B 연결, 얼굴 바로 확대. 실제 사진으로 묶음 오류를 검증.
4. 품질 의심 표시와 메모 포함 사본은 실제 요구·호환성 확인 후 추가.

예상 흐름: 좋음까지 포함한 후보 → 인물 태그로 좁히기 → 애매한 컷 다시 보기 → A/B 비교 → 가족 공유 세트 확정 → 태그·메모·사진 함께 내보내기. 이 흐름의 효용은 아직 실제 사용자로 검증하지 않았다.

초기 제외 추천: 강제 토너먼트, 자동 삭제·미적 점수로 최종 N장 강제 확정, 이름별 얼굴 인식, SNS 자동 게시, 종합 사진 편집기.
