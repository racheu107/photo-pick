# 사진 평가 디자인·모션 에이전트 회의

후속 사용자 수정: [v2 회의](evaluation-design-meeting-v2-2026-10-12.md)의 기본 위쪽 계단 스택·다음 카드 정착·평가 버튼 흡수가 아래 초기 권고를 대체한다. 이 문서는 초기 제안 이력이다.

일자 2026-10-12. 사용자 요청에 따라 시각 디자인 담당과 모션 UX 담당 에이전트가 현재 d15 평가 화면·소스와 첨부 모음의 카드 4개를 검토하고 교차 의견을 교환했다. 실제 사용자 인터뷰나 실험 결과가 아닌 제안이다. 이번 회의의 디자인은 구현하지 않았다. 별도 요청한 확대 유지만 d16에 적용한다.

## 참고 자료와 한계

현재 화면: `design-preview/verification/d15/controls-320.png`, `actual-apk-controls.png`. 소스: Android www의 `review-ui.js`, `ui-motion.js`, `design-preview.css`.

첨부 모음은 매우 좋음 진입 중 작은 카드 회전, 일반 사진 평가 카드, 약한 회전이 있는 슬라이드, 아래 내림 카드의 네 방향을 보여준다. 원본 JPG 네 파일은 현재 PC의 지정 경로와 프로젝트에서 찾지 못했다. 작은 모음에서 그림자·움직임 궤적·실제 사진 비율까지 확정하지 않았다.

## 세 방향

| 방향 | 정지 상태 | 움직일 때 | 장점·주의 |
| --- | --- | --- | --- |
| 담백한 사진형 | 원본 비율, 어두운 무채색 배경, 작은 둥근 모서리 | 회전 없이 가로/세로 이동 | 사진 판독 중심. 손으로 넘기는 감각은 약할 수 있음 |
| 절제된 카드형 — 추천 | 담백한 사진형과 동일, 액자·그림자 최소 | 뒤 한 장을 얕게 노출, 좌우에 작은 회전 | 사진 면적과 카드의 손맛을 함께 유지 |
| 감성 카드형 | 사선 뒤 카드·조금 더 깊은 명암 | 매우 좋음에 약한 축소·반짝임 | 개성은 강하지만 반복 작업의 집중·리듬을 해칠 수 있어 비교 시안으로만 검토 |

현재 구현에도 이미 손가락 추종·작은 회전·뒤 한 장·취소 복귀가 있다. 추천안은 구조를 새로 만드는 작업보다 강도와 평가 의미를 정돈하는 방향이다.

## 합의한 시각 규칙

- 앞 사진은 전체 비율과 구도를 유지한다. 사선 모서리를 앞 사진에 넣어 잘라내지 않는다.
- 첨부의 사선/입체 모서리를 살린다면 뒤 카드에만 제한한다.
- 강한 흰 액자·깊은 그림자·여러 카드 더미는 기본안에서 제외한다.
- 현재 어두운 무채색 배경을 유지한다. 사진을 흐려 배경 전체에 반복하면 색과 밝기 판단에 간섭할 수 있다는 가설이 있다.
- 뒤 사진은 기본적으로 숨기고 조작할 때 한 장의 얕은 가장자리만 보여준다.
- 가로 사진은 세로 카드로 채우지 않고 자체 비율을 유지한다.
- 확대 상태에서는 카드 회전·뒤 카드·등급 스와이프를 멈추고 사진 내부 이동에 집중한다. 정지 확대에서는 평가 버튼을 사용할 수 있어야 한다.

## 모션별 제안

| 행동 | 제안 |
| --- | --- |
| 좌우 탐색 | 손가락을 따라 이동하고 약하게 기울임. 좋아요/싫어요 색 대신 이전/다음만 표시 |
| 아래 좋음 | 거의 회전 없이 아래로 이동. 확정 거리 전에는 복귀 가능 |
| 확정 거리 전에 놓기 | 원래 위치 복귀, 평가 불변 |
| 좋음 버튼 | 아이콘·테두리를 짧게 강조한 뒤 실제 다음 미평가 사진 표시 |
| 매우 좋음 버튼 | 동일한 전환 리듬, 버튼 주변에 은은한 샴페인색 강조 한 번 |
| 별로 버튼 | 중립 회색 피드백, 다른 평가와 같은 전환 시간 |
| 마지막 평가 | 다음 빈 카드 대신 결과 화면으로 이동한다는 피드백 |
| 로딩 지연·실패 | 도착할 사진이 준비되기 전 현재 사진 유지, 실패 시 현재 사진 복귀 및 안내 |
| 움직임 감소 | 이동·회전을 없애고 짧은 버튼 강조/즉시 교체로 의미 유지 |

사진 전체를 색으로 덮거나 큰 하트/별 스탬프를 씌우는 방식, 매우 좋음에서 사진이 작아져 멀리 날아가는 방식은 기본안에서 제외 권고다. 앞 사진은 평가 대상이고 버튼 주변은 평가 결과를 표시하는 영역으로 구분한다. 다음 사진에 이전 등급 피드백이 남지 않도록 한다.

뒤 카드의 실제 대상도 구분한다. 좌우는 실제 이전·다음, 아래 평가는 다음 미평가다. 이미 평가한 컷을 건너뛸 때 미리보기와 실제 도착 사진이 같아야 한다.

후보 수치: 좌우 회전은 현재 최대 ±1.5°를 기본으로 3°와 비교, 취소 복귀 160~200ms, 확정 전환 120~180ms. 검증된 최적값이 아니라 프로토타입 비교용이다. 매우 좋음만 더 오래 재생하지 않는다.

## 다음 시안에서 비교할 항목

절제된 카드형과 담백한 사진형을 같은 사진 묶음으로 비교한다. 세로·가로·밝은·어두운 사진과 연속 평가, 평가 취소, 로딩 실패, 확대 후 평가를 포함한다. 완료 시간, 원치 않은 평가, 복귀 시도, 피로·선호를 관찰한다. 개성 있는 사선 뒤 카드와 샴페인 강조는 두 번째 비교 항목으로 둔다.

## 확대 유지와의 연결

모션 담당은 확대 상태 전체가 busy에 포함되어 버튼 평가가 막힐 수 있다고 지적했다. d16에서는 정지 확대와 진행 중 핀치/팬을 분리하고 손을 뗀 뒤 평가 버튼을 복구한다. 평가·다른 사진 이동 시 전체보기로 초기화하며 더블탭과 전체보기 버튼을 제공한다. 이 변경은 사용자에게 별도 승인받은 확대 유지 요청의 구현이다.
