# 서랍 스택·버튼 흡수·유리 조작부 — 0.2.23 d17

2026-10-12. 사용자가 재생 미리보기를 확인한 뒤 앱 적용을 요청했고, 버튼을 사진보다 앞에 배치하며 첨부의 둥근 반투명 바와 뒤쪽 블러를 참고하도록 추가 지정했다. 마지막 수정인 ‘넘길 때 바로 뒤 사진 블러 유지’를 우선했다.

## 적용 내용

- 기본은 앞 사진 한 장 + 실제 다음 미평가 후보 최대 세 장. 뒤로 갈수록 .96/.92/.88 크기, 위 10/20/30px, .6/.35/.18 불투명도, 2/3/4px 블러. 남은 후보가 적으면 실제 개수만 보인다.
- 좌우 탐색의 실제 이전/다음과 아래 평가의 다음 미평가를 구분해 미리보기 대상이 실제 도착 사진과 일치한다.
- 뒤 첫 사진은 위에서 조금 내려오며 진해지지만 .96 크기와 2px 블러를 유지한다. 앞 사진이 완전히 퇴장한 뒤에 새 앞 사진이 90ms 동안 정상 크기·위치·선명도로 정착한다.
- 좌우 퇴장 170ms, 평가 버튼 흡수 190ms. 평가 사진은 확정 등급 버튼의 실제 중심으로 약하게 회전·축소하고 마지막 구간에 사라진다. 버튼 피드백은 짧게 표시하고 다음 사진에 평가 표시를 남기지 않는다.
- 흡수 사진은 사진 영역 밖의 별도 레이어에서 움직이며 z-index 5, 조작부 z-index 10으로 버튼 뒤에 들어간다. 유리 바의 backdrop-filter 16px는 지나가는 사진을 흐리게 보여준다. 앞에서 움직이는 사진 자체에 모션 블러를 넣지는 않는다.
- 조작부는 기존 초기화/별로/좋음/매우 좋음 아이콘·56px 평가 버튼을 유지하고 하나의 둥근 반투명 바 형태로 정돈했다. 첫 기본 스타일은 유리이며 저장된 무광/유리 선택은 유지한다. 평가 흡수 중에는 뒤쪽 블러를 적용한다. 투명도 감소 선호 시에는 불투명 대안을 제공한다.
- 확정 전 취소에서는 앞 사진과 뒤 스택이 함께 복귀한다. 확대 상태에서는 스택을 숨기고 핀치·팬을 우선한다. 정지 확대에서 평가 버튼을 사용할 수 있으며 확대된 자세를 이어 받아 흡수한다. 다음 사진은 전체보기다.
- 평가 해제는 현재 사진에 머문다. 이미 매우 좋음인 사진의 아래 평가는 매우 좋음을 유지하고 그 버튼으로 향한다. 모든 사진 평가 완료 시에도 마지막 평가 흡수 후 결과 화면으로 간다.
- 로딩이 준비되기 전 현재 사진을 완전히 퇴장시키지 않는다. 실패하면 현재 사진과 이미 받아들인 평가를 유지하고 재조작할 수 있게 복구한다. 중간 화면 이동 시 취소하여 나중에 자동 이동하지 않는다.
- JPEG 전체 구도는 object-fit:contain으로 유지하며 공통 카드 표시 영역을 사용한다. 기존 사진 읽기·원본 복사·권한·평가 등급은 유지한다. 최종 N장/A·B 기능은 제거 상태를 유지한다.
