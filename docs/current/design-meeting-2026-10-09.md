# Photo Pick 디자인 팀 회의: 0.2.7과 코랄 시안의 중간안

회의일: 2026-10-09 (한국 시간)
참여 역할: 디자인 리드, 인터랙션 디자이너, 비주얼·접근성 디자이너. 각자 기존 캡처와 시안을 확인한 뒤 제안을 공유하고 교차 검토했다.
상태: 회의 제안, 앱 미구현. 실제 사용자 테스트나 확정된 새 디자인이 아니다.

## 사용자 후속 결정 — 이 항목을 이전 회의안보다 우선

### d2 최종 사용자 피드백과 구현

사진 위 즐겨찾기를 제거하고 하단만 사용한다. 작은 원형 되돌리기 / 가운데 X·하트 묶음 / 작은 원형 반짝임(매우 좋음)으로 구성한다. 코랄은 중성 그래파이트·회색으로 대체한다. 디자인 회의 크기는 양끝 48px, 중앙 128×56px, 간격 12px이다.

매우 좋음은 좋음+별 표시로, 하트와 반짝임이 동시에 활성화된다. 별 재탭은 좋음 유지, 하트 재탭은 미선택, 좋음에서 별을 켜면 매우 좋음, 매우 좋음에서 되돌리기는 미선택으로 초기화, 매우 좋음에서 별로를 누르면 별로로 변경한다. 좌우 왕복 시 평가 표시를 유지하고 아래 스와이프는 매우 좋음을 보존한다.

이 결정은 이전의 코랄·사진 위 별·별 재탭 시 미평가·단일 버튼만 활성·매우 좋음 상태의 일반 이력 Undo 규칙을 대체한다. 소비자 페르소나 검토와 반영 사항은 persona-review-d2-2026-10-09.md에 기록한다.

### 제스처 피드백 확정

사용자가 방향별 그라데이션·아이콘·문구와 모션으로 조작 결과를 예고하는 안에 동의했다.

- 오른쪽 드래그: 왼쪽 가장자리 중성 그라데이션과 ‘이전 사진’/왼쪽 화살표.
- 왼쪽 드래그: 오른쪽 가장자리 중성 그라데이션과 ‘다음 사진’/오른쪽 화살표.
- 아래 드래그: 아래쪽 코랄 그라데이션과 하트·‘좋음’. 이미 매우 좋음이면 별·‘매우 좋음 유지’로 실제 결과를 예고한다.
- 카드는 손가락을 조금 따라 움직이고 실행 기준에 가까워질수록 피드백을 선명하게 한다. 평가·이동은 손을 놓아 실행 조건을 충족했을 때 확정한다.
- 짧은 드래그·원위치 복귀·취소에서는 효과를 지우고 평가/이동하지 않는다. 첫·끝 사진의 없는 방향에서는 실제 이동을 예고하지 않는다.
- 사진 전체를 물들이지 않고 가장자리 중심으로 효과를 적용한다. 기본 상태에서는 사진에 착색을 남기지 않는다.
- 첫 사용자에게 처음 한 번 짧은 시범 모션을 제공한다. 드래그 피드백만으로 제스처 발견을 대체하지 않는다.
- 확대·두 손가락 조작 중에는 탐색/평가 제스처와 해당 피드백을 끄고 사진 팬·줌만 처리한다. 모션 감소 설정에서는 큰 이동 시범을 줄이고 아이콘·문구 안내로 기능을 유지한다.

이 항목은 기획 확정 기록이다. 애니메이션 거리·임계값·시간·불투명도는 작동 시안에서 조정하며 앱 구현은 아직 하지 않았다.

추가 사용자 결정: 버튼은 최초 평가·재평가·해제 모두 지원한다. 스와이프는 익숙한 사용자의 편의 조작이고 버튼은 첫 사용자도 전체 평가 기능을 수행할 수 있는 경로다. 버튼은 기존 평가 수정만을 위한 수단이 아니다. 버튼으로 평가 시 현재 사진에 머물며 다음/이전 탐색 버튼도 제공하는 기존 절충안과 연결한다.

하단은 글자보다 아이콘 중심을 원한다. X는 취소/삭제 등으로 오해할 수 있어 대체한다. 검토 후보는 되돌리기 곡선 화살표 / 별로 엄지 아래 / 좋음 하트 / 매우 좋음 별. 이 아이콘 후보는 에이전트 제안이며 사용자가 최종 선택한 것은 아니다. 하단과 사진 우상단의 매우 좋음은 같은 별을 쓴다. 아이콘은 기존 UI와 선 굵기·크기·활성 채움 규칙을 맞춘다. 처음 한 번 짧은 의미 안내와 접근성 이름·선택 상태를 제공하되 상시 버튼 텍스트를 강제하지 않는다. 실제 아이콘 자산이나 앱 코드는 아직 변경하지 않았다.

페르소나 검토 후 사용자가 2026-10-09에 결정했다.

- 아주 좋음(best)은 좌우 이동과 아래 스와이프 후에도 유지한다. 아래 스와이프는 아주 좋음을 좋음으로 낮추지 않고 다음 사진으로 이동한다.
- 아주 좋음은 현재 활성 즐겨찾기/아주 좋음 아이콘을 재탭해 미평가로 해제하거나, 다른 평가 버튼을 명시적으로 눌렀을 때만 변경한다.
- 하단에 작은 되돌리기 아이콘을 다시 추가한다. 구성: [되돌리기] [별로 / 좋음] [매우 좋음 아이콘]. 별로와 좋음은 그룹 안의 각각 독립 버튼이다.
- 마지막 아이콘과 사진 우상단 즐겨찾기는 기존 best라는 같은 등급을 표시한다. ‘아주 좋음 / 매우 좋음’ 두 이름으로 별도 등급을 만들지 않는다. 사용자 표현 ‘매우 좋음’은 마지막 버튼의 명칭 후보이며 최종 앱 문구는 통일한다.
- 작은 되돌리기는 시각적 크기를 줄이되 터치 영역까지 작게 만들지 않는다.
- 되돌리기의 세부 대상은 후속 구현 권고로 직전 완료 행동의 위치·평가를 함께 복원한다. 탐색과 평가+자동 이동을 각각 한 행동으로 기록한다. 이 세부 규칙은 사용자 직접 명시 사항과 구분한다.

이 후속 결정은 아래의 ‘Undo 제외’, ‘아주 좋음에서 아래로 내리면 강등’ 우선안을 대체한다. 기존 회의 내용은 논의 이력으로 남긴다. 현재는 기록만 갱신했으며 앱 코드·배포를 변경하지 않았다.

## 최신 사용자 결정

- 오른쪽 스와이프는 이전 사진, 왼쪽은 다음 사진. 이동만으로 평가는 바뀌지 않는다.
- 아래로 내리기는 좋음 평가. 사진 오른쪽 위 즐겨찾기는 아주 좋음.
- Undo는 제외한다.
- 하단 평가 버튼은 현재 사진 상태를 표시한다. 같은 평가 재탭은 취소, 다른 평가 탭은 교체한다.
- 직전 설명과 시안 기준으로 버튼은 현재 사진에 머물며 아래 평가는 다음 사진으로 이동하는 안이다.
- 사용자는 생성한 코랄 시안을 긍정적으로 평가했으며, 현재 버전과 조율하는 중간안을 요청했다.

이 결정은 앞선 design-review-2026-10-09.md의 Undo 권고·아주 좋음 입력 미결정을 대체한다. 이전 문서는 당시의 검토 이력으로 남긴다.

| 화면 테마 | 밝은 불러오기·앨범·결과, 어두운 집중 평가 | 로고 점과 긍정 평가에 톤다운 코랄 |

| 취소 | 되돌아가 평가 수정 가능 | Undo와 별도 ‘평가 취소’ 행 제거, 현재 평가 재탭으로 해제 |

사진 즐겨찾기는 화면 상단 고정 좌표가 아니라 실제 사진 프레임 우상단 안쪽에 붙인다. 밝은 사진에서도 보이도록 어두운 표면을 두고 약 48dp 터치 영역을 확보한다. 하단 아주 좋음과 하나의 평가 상태를 공유한다.

## 동작 계약 제안

평가 상태는 미평가·별로·좋음·아주 좋음을 구분한다. X는 명시적 별로 평가이며 좌우 넘김과 다르다. 이는 시안에서 X를 별로로 표시한 해석을 따른 회의 제안이다.

- 좌우: 날짜 선택 범위에서 이전/다음 순번, 평가 유지. 경계에서 순환하지 않는다.
- 버튼: 미평가에서 탭하면 평가, 같은 활성 버튼 재탭하면 미평가, 다른 버튼 탭하면 교체. 사진은 머문다.
- 상단 즐겨찾기: 아주 좋음 설정/해제. 하단 별과 동시에 갱신.
- 아래: 좋음 평가 후 다음 순번. 이미 좋음이라면 같은 평가를 유지하고 다음 순번.
- 마지막 사진에서 아래: 사진에 머무르며 마지막 장 안내와 평가결과 진입 제공. Undo가 없어도 재탭 수정 경로를 유지한다. 이 경계 동작은 회의 권고이며 사용자 확정 전이다.
- 확대/두 손가락: 사진 팬·줌만 처리, 넘김/평가 제스처를 차단. 손가락 수 변경과 대각선·기준 거리 미달은 평가 확정하지 않는다.
- 잘못 아래로 평가한 경우: 오른쪽으로 이전 사진 복귀 → 활성 좋음 재탭 → 미평가로 복구.

## 회의 이견: 아주 좋음 사진을 아래로 내릴 때

디자인 리드는 사용자의 아래=좋음 계약을 일관되게 적용해 좋음으로 변경하고 다음으로 이동할 것을 권고했다. 인터랙션 디자이너는 실수로 강등되는 것을 막기 위해 아주 좋음을 유지하고 다음으로 갈 것을 권고했다.

종합 우선안은 사용자 설명 그대로 좋음으로 변경하는 것이다. 사용자가 보존 예외를 선택하지 않은 상태에서 임의로 예외를 넣지 않는다. 단, 구현 전 이 상황을 시안 테스트에 포함한다. 이는 논의된 이견이며 아직 별도 사용자 결정은 없다.

## 색상 후보와 대비 계산

색 코드는 회의 후보이며 최종 팔레트 확정이나 전체 접근성 통과를 뜻하지 않는다. 아래 값은 sRGB 상대휘도 공식으로 계산한 불투명 단색 대비다. 블러·사진·투명도를 합성한 실제 화면은 별도 검증해야 한다.

| 용도 | 후보 | 대비 |
| --- | --- | --- |
| 집중 배경 / 바 | #141619 / #22252B | 사진 감상용 중립 배경 |
| 어두운 화면의 활성 코랄 | #F29086 | #22252B 위 아이콘 6.66:1 |
| 코랄 버튼의 어두운 문구 | #141619 on #F29086 | 7.86:1 |
| 밝은 화면의 코랄 문구 | #B94E48 on #FFF8F5 | 4.71:1 |
| 피할 조합 | 흰 글자 on #FF8178 | 2.42:1, 작은 글자 기준 미달 |

좋음은 하트, 아주 좋음은 별로 구분하고 코랄 농도만으로 구별하지 않는다. 아주 좋음에 골드를 추가하는 안은 이번 중간안에서 보류한다.

## 이번 단계에서 보류할 항목

큰 흰색 사진 위 플로팅 바, 전면 블러 UI, 사진 크롭, 카드 스택, 필름스트립, 얼굴 자동 확대, 스마트 추천. 현재 화면의 사진 판단과 조작 안정성을 먼저 유지한다.

## 검증할 장면

1. 세로·가로 사진과 작은 화면에서 사진 전체/별/3등급 문구/48dp 터치 영역이 겹치지 않는다.
2. 밝은 하늘·야경·복잡한 배경에서도 즐겨찾기와 상태 표시를 읽을 수 있다.
3. 같은 평가 재탭·타 평가 교체·즐겨찾기 동기화 시 선택 개수와 결과 목록이 정확하다.
4. 아래 평가 후 오른쪽 복귀로 즉시 수정할 수 있고, 마지막 사진에서도 수정 경로가 유지된다.
5. 확대 팬·대각선·취소·연타에서 의도치 않은 평가나 중복 이동이 없다.
6. 기존 평가 기록과 사진 전환 깜빡임 수정이 유지된다.

## 이어서 작업할 때

최신 동작은 이 문서의 사용자 결정과 이후 사용자 답변을 우선한다. 기존 파일과 생성 시안은 비교 자료다. 다음 단계는 이 중간안을 반영한 시안 확인 또는 구현이며, 현재 회의에서는 앱 코드·배포를 변경하지 않았다.
