# 사진 평가 모션 회의 v2 — 위쪽 서랍 스택

2026-10-12. 사용자가 직접 수정한 01 기본·02 좌우·03 아래 평가와 새 원본 이미지를 기준으로 시각 디자인·모션 UX 에이전트 2명이 재검토하고 교차 합의했다. 제안·실험 후보이며 실제 사용자 검증 결과가 아니다. 앱 코드·APK는 변경하지 않았다. 나머지 승인된 버튼 피드백과 취소 복귀 방향은 유지한다.

## 최신 사용자 방향

1. 기본 상태에서도 실제 다음 사진들이 위쪽으로 계단식 겹침을 보인다. 뒤로 갈수록 작게·연하게·블러.
2. 좌우 슬라이드에서 뒤 사진이 측면에 크게 펼쳐지지 않는다. 위에서 조금 내려오며 진하고 선명해진다. 앞 사진이 완전히 넘어간 뒤에만 정상 크기가 된다.
3. 아래 평가 확정 후 사진은 해당 평가 버튼 쪽으로 약하게 회전하고 작아지며 흡수된다.

이 방향은 이전 회의의 ‘정지 시 뒤 카드 숨김’, ‘축소 흡수는 기본안에서 제외’ 권고를 대체한다. 이전 제안과 생성 시안은 비교 이력으로 보존한다.

## 01 기본

원본 첨부를 직접 확인했다. 앞 카드 1장 + 위쪽 뒤 카드 최대 3장. 뒤에는 실제 이동할 후보를 사용하며 남은 사진이 적으면 실제 개수만 표시한다.

| 카드 | 크기 | 상단 위치 | 불투명도 | 블러 |
| --- | --- | --- | --- | --- |
| 현재 | 100% | 기준 | 100% | 없음 |
| 다음 | 96% | 위 10px | 60% | 1px |
| 그다음 | 92% | 위 20px | 35% | 2px |
| 세 번째 뒤 | 88% | 위 30px | 18% | 3px |

360px 안팎의 화면 폭을 기준으로 한 시안 값이며 확정 규격이 아니다. 상단 중심을 축소 기준점으로 삼고 상단 약 30~36px의 계단 영역을 확보한다. 앞 사진 면적을 지나치게 줄이지 않는다. 강한 그림자를 겹치기보다 크기·연함·블러로 깊이를 표현한다.

공통 사진 표시 카드 안에 원본 전체를 맞춘다. 가로·세로 사진을 늘리거나 최종 앞 사진을 크롭하지 않는다. 남는 영역은 무채색으로 두고, 뒤 카드 바탕·상단 겹침을 공통 기준으로 정렬한다.

## 02 좌우 슬라이드

| 단계 | 현재 사진 | 다음 도착 사진 |
| --- | --- | --- |
| 정지 | 원래 크기·선명 | 작은 상단 스택 |
| 손가락 이동 | 이동에 따라 좌우로 나감, 작은 회전 | 위에서 조금 내려옴, 점점 진하고 선명. 작은 크기는 유지 |
| 확정 퇴장 | 놓은 위치에서 이어서 화면 밖으로 | 작은 상태로 대기 |
| 현재 사진 완전 퇴장 | 제거 | 정상 크기와 위치로 안착 |
| 취소 | 현재 자세에서 원위치 복귀 | 내려온 만큼 스택으로 복귀 |

진행률 후보: 첫 뒤 카드 y -10→-3px, opacity .6→.9, blur 1→0px. scale .96은 앞 카드가 완전히 퇴장할 때까지 유지한다. 이후 scale .96→1, y -3→0, opacity .9→1로 정착한다. 회전은 앞 사진에만 약 2~3° 후보를 시험한다.

놓은 뒤 앞 사진 퇴장 150~190ms + 다음 사진 정착 70~100ms, 합계 220~290ms를 초기 비교 범위로 제안했다. 실제 빠르기·편안함을 검증한 수치가 아니다. 고정 시간만으로 상태를 넘기지 않고 앞 카드 퇴장 완료 시점을 연결한다.

기본 스택은 미래 후보지만 오른쪽 이전 탐색의 도착 사진은 다르다. 도착 대상을 제스처 시작 시 상단 스택의 첫 카드에 연결하고, 측면 대형 사진으로 펼치지 않는다. 미리보기와 실제 이동 사진이 같아야 한다.

## 03 아래 평가 — 버튼으로 흡수

확정 거리 전에는 사진이 손가락을 따라 아래로 움직이고, 이때 놓으면 복귀한다. 임계값을 넘겨 놓아 확정한 뒤에만 흡수 모션을 시작한다.

현재 사진 → 실제 평가 버튼 중심으로 부드러운 곡선 이동 → 약한 회전·비례 축소 → 마지막 구간에서 투명해짐 → 버튼의 짧은 완료 강조 → 위 스택의 다음 미평가 사진 정착.

현재 사진은 이동 중에도 선명하게 유지한다. 사용자 요청 블러는 뒤 카드의 깊이 표현에 한정하고 전경의 속도 잔상은 만들지 않는다. 버튼마다 같은 시간·구조를 사용하고 목적지 및 작은 색상 강조만 구분한다.

아래 좋음 평가의 기본 목적지는 하트다. 현재 앱은 매우 좋음 사진을 아래로 넘겨도 매우 좋음을 유지하므로 이 경우 목적지는 매우 좋음 버튼이다. 평가 해제는 현재 사진에 머물고 흡수·다음 사진 공급을 하지 않는다. 실제 확정 등급에 맞춰 경로를 정해야 한다.

## 참고 글 적용

[Good to great UI animation tips](https://uxdesign.cc/good-to-great-ui-animation-tips-7850805c12e5)는 전후 상태의 연속성과 공유 요소의 연결, 버튼 자체의 상태 표현을 다룬다. 스택의 뒤 사진이 다음 앞 사진으로 이어지고 평가 사진이 버튼의 완료 강조로 연결되는 방향에 적용한다. 스택의 모든 작은 요소를 별도 순차 재생하는 것은 피한다.

[The ultimate guide to proper use of animation in UX](https://uxdesign.cc/the-ultimate-guide-to-proper-use-of-animation-in-ux-10bd98614fa9)는 가감속·중심 요소에 따른 안무·불필요한 대기 억제를 설명한다. 현재 사진의 퇴장을 먼저 읽고 다음 사진이 정착하도록 순서를 연결한다. 글의 모션 블러 주의는 움직이는 앞 사진에 잔상을 만들지 않는 원칙으로 참고하며, 뒤 카드 깊이를 나타내는 블러와 구분한다.

두 글은 2018년 디자인 조언이다. 시간·기술 관련 표현을 보편적 최신 규칙이나 Photo Pick 사용자 실험 결과로 취급하지 않는다. 사용자 요청과 제품 맥락을 우선한다.

## 예외와 검증할 항목

- 확대에서는 스택·회전·등급 드래그를 멈추고 핀치·팬 우선. 정지 확대의 버튼 평가는 허용하고 다음 사진은 전체보기.
- 좌우는 실제 이전/다음, 아래는 다음 미평가로 대상 구분.
- 로딩 대상이 준비되기 전 현재 사진을 완전히 없애지 않는다. 실패 시 현재 사진 복귀와 실제 평가 저장 상태가 일치해야 한다.
- 빠른 연속 탭을 다음 사진의 평가로 미리 예약하지 않는다.
- 움직임 감소 모드에서는 회전·흡수·크기 전환 대신 정적 스택·짧은 버튼 강조·즉시 교체.
- 같은 크기의 외곽 카드에서 가로·세로·정사각형 사진이 바뀔 때 구도 전체와 선명도를 확인한다.

다음 시안은 기본 스택, 슬라이드 중간, 앞 사진 퇴장 직후, 아래 흡수 중간, 버튼 도착, 다음 사진 정착을 비교하도록 한다. 큰 전환의 순서는 동작 프로토타입으로 확인해야 하며 정지 이미지가 타이밍을 검증하는 것은 아니다.
