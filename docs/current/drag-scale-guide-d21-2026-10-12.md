# 드래그 축소·첫 사용 안내 — 0.2.27 d21

## 적용

- 좌우 드래그 진행에 따라 사진을 최대 7%, 아래 드래그는 최대 8% 축소. 좌우 확정 퇴장은 90% 크기까지 이어짐. 취소는 크기·위치·회전 모두 원위치로 복귀.
- 기존 하단 중앙 회전축과 좌우 22.5도 퇴장, 평가 버튼 흡수 유지. 확대 검사 중에는 기존 팬 동작 우선.
- 기존 첫 진입 텍스트 안내를 어두운 오버레이·흰 문구·화살표·사진 복사본 시연으로 교체.
- 왼쪽(다음) → 오른쪽(이전) → 아래(좋음)를 순서대로 시연. 실제 사진 이동·평가·진동을 실행하지 않음.
- 동일 기능의 드래그·버튼을 화살표와 문구로 연결. 별로·좋음·매우좋음 버튼도 안내 하단에 표시.
- 건너뛰기 항상 제공, 다음/시작하기로 직접 단계 이동 가능. 완료·건너뛰기 후 다시 표시하지 않음. 업데이트 사용자도 새 안내를 한 번 볼 수 있도록 별도 완료 기록 사용.
- 안내 중 실제 컨트롤 입력 차단, 화면 이탈·취소 시 원래 사진과 컨트롤 복구. 움직임 감소에서는 정적 안내와 수동 단계 이동.
