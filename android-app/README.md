# Photo Pick Android

Android 10 이상용 앱입니다. 화이트·차콜·블루 디자인과 세 단계 평가를 앱 안에 포함합니다. 사진을 서버로 올리지 않습니다. 촬영 위치의 지명 안내는 기기 Geocoder 서비스의 지원 및 연결 상태에 따라 표시됩니다.

## 기능

- 연결된 외장 저장소에서 폴더 선택 시작, 승인했던 폴더 재연결 및 다른 폴더 선택
- 하위 폴더 JPEG 읽기와 원본 비율 미리보기
- EXIF 촬영일별 그룹 선택, 촬영일 없음 별도 그룹, 장소는 날짜 아래 보조 안내
- 사진 밖의 버튼·앨범에서 별로 / 좋음 / 아주 좋음 평가 (스와이프 평가 없음)
- 두 손가락 핀치 1~3배 확대, 모든 손가락을 떼면 원복, 확대 시 고해상도 미리보기
- 같은 폴더 재선택 시 평가 복원
- 평가 결과에서 아주 좋음만 / 좋음까지 포함 선택
- 원본 JPEG를 갤러리의 Photo Pick 앨범(Pictures/Photo Pick)에 저장
- 저장 진행률·중단·부분 실패 안내, 앱에서 이미 저장한 원본 재저장 방지

사진을 삭제하거나 다시 평가해도 SD카드 원본은 수정하지 않습니다. 앨범 저장은 JPEG 바이트를 그대로 복사하여 메타데이터를 유지합니다. 미리보기만 축소합니다. 예시 사진은 체험 흐름이며 실제 저장 기능 검증은 SD카드 사진으로 해야 합니다.

## 빌드

Android Studio에서 이 폴더를 열거나, JDK 17과 Android SDK 35 환경에서 실행합니다.

```
./gradlew assembleDebug lintDebug
```

GitHub Actions의 Build Android APK 작업에서도 빌드합니다. 성공한 실행의 PhotoPick-debug-apk 아티팩트에 설치용 app-debug.apk가 있습니다. 배포 파일은 테스트용 debug APK이며 Play Store 배포용 서명은 포함하지 않습니다.

## 실제 기기 확인

1. APK를 휴대폰에 설치하고 SD카드 리더기를 연결합니다.
2. 앱에서 SD카드 사진 폴더를 선택합니다. 시스템 선택기가 SD카드 자체 루트를 허용하지 않으면 DCIM 등 하위 폴더를 선택합니다.
3. 세 등급으로 평가하고 저장 범위를 바꾸어 갤러리 Photo Pick 앨범의 원본 사진을 확인합니다.
4. 같은 사진 재저장, 저장 중 취소, SD카드 분리, 저장 공간 부족을 확인합니다.
5. 앱을 종료한 뒤 같은 폴더를 선택하여 평가 복원을 확인합니다.

빌드·브라우저 어댑터 검증과 실기기 검증은 별도입니다. 갤러리 앱에 따른 앨범 표시, 실제 리더기 호환성, 대량 사진 성능은 기기에서 확인해야 합니다.


### 0.2.1 선택 흐름
- 메인 SD카드 연결 버튼은 매번 시스템 폴더 선택창을 엽니다. 아래 이어서 평가는 기존 세션과 승인 폴더로 재연결합니다.
- 로딩 중 사진 목록을 먼저 확인하고 전체 장수가 확정되면 불러온 장수/전체 장수와 사용 팁을 표시합니다.
- 사진그룹 선택 화면은 전체 해제로 시작합니다. 촬영일별 그룹, 왼쪽 체크박스, 평가(완료/전체장) 표시 및 전체 선택/해제 토글을 제공합니다.
- 사진그룹 선택에서 메인으로 돌아갈 때 확인창을 표시하며 평가 기록은 보존합니다.


### 0.2.2 앱 내부 업데이트
- 앱 실행 시 공개 GitHub Releases 최근 100개에서 android-vX.Y.Z(-preview) 태그와 해당 버전 PhotoPick-X.Y.Z-debug.apk를 확인합니다. 초안은 제외하고 테스트 릴리스도 포함합니다.
- 현재 버전보다 높은 버전만 메인 화면이 활성 상태이고 다른 창/사진 작업이 없을 때 안내합니다. 메인 메뉴의 앱 업데이트 확인으로 수동 재검사할 수 있습니다. 자동 확인 실패는 사진 작업을 막지 않습니다.
- 사용자가 업데이트를 선택하면 cache/updates에 내려받습니다. 일반 다운로드 폴더에는 쓰지 않습니다. 다운로드 중 취소 가능합니다.
- HTTPS 허용 호스트와 릴리스 자산 경로, 파일 크기, GitHub digest가 있으면 SHA256, APK 패키지/버전명/증가한 versionCode/기존 서명 일치를 검사합니다. 사진 원본과 메타데이터는 업데이트 요청에 포함하지 않습니다.
- REQUEST_INSTALL_PACKAGES를 사용하며 필요하면 이 출처 허용 설정을 안내합니다. 실제 설치는 Android 확인창에서 사용자 승인 및 시스템 검증을 거칩니다.
- 설치 완료 후 다음 실행 시 설치된 버전 이하 APK를 삭제합니다. 부분 다운로드/잘못된 파일은 정리하며, 미설치 APK는 48시간 경과 후 앱 실행 시 정리합니다. 앱이 실행되지 않은 상태에서 48시간마다 정리하는 백그라운드 작업은 없습니다.
- 최초 0.2.2는 직접 설치해야 이후 업데이트 안내가 작동합니다. 이후 배포 파일은 같은 키와 증가한 versionCode가 필수입니다. 로컬 debug 키는 저장소에 올리지 않으며 CI 임시 debug 키로 만든 파일은 업데이트 릴리스로 사용하지 않습니다.
- 검증 러너: adb shell am instrument -w com.photopick.app.test/com.photopick.app.UpdaterChecks. 선택적으로 download=true, futureApk=<같은 서명의 현재 설치본보다 높은 버전 테스트 APK 경로> 인수로 다운로드와 설치 연결을 검증합니다. fixture APK는 공개 배포하지 않습니다.


### 0.2.3 차분한 갤러리 스타일
- 블루는 SD카드 연결, 선택한 사진 평가 시작, 저장 같은 주 행동과 평가 버튼의 순간 피드백에 사용합니다. 보기 전환, 전체 선택/결과 링크, 등급 아이콘/뱃지, 진행률과 체크박스는 중성색으로 정리했습니다.
- 로딩은 불투명 화이트 화면으로 이전 화면을 완전히 가리고, 번들 풍경 사진을 흐리게 가공한 3장의 우윳빛 카드가 작은 폭으로 정렬되는 장식을 표시합니다. 실제 사용자 사진을 장식 목적으로 읽거나 전송하지 않습니다.
- 장수는 기존 실제 읽기 이벤트를 사용합니다. 전체 장수가 확정되기 전 진행 바는 숨기고, 확정 후 실제 진행률만 회색 바로 보여줍니다. 동작 줄이기에서는 로딩 카드와 진행 바 모션을 생략합니다.
- 사진 아래 단일 평가 도구, 정돈된 글자 위계, 라운드와 여백을 적용했습니다. 폴더 선택/촬영일 그룹/평가/저장/업데이트 데이터 흐름은 유지합니다.
- quiet-glass.css가 기존 시각 레이어 뒤에서 스타일을 적용합니다. APK 버전 0.2.3, versionCode 6이며 기존 로컬 debug 키를 유지합니다.
