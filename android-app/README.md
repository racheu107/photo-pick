# Photo Pick Android

Android 10 이상용 앱입니다. 화이트·차콜·블루 디자인과 세 단계 평가를 앱 안에 포함합니다. 사진을 서버로 올리지 않습니다. 촬영 위치의 지명 안내는 기기 Geocoder 서비스의 지원 및 연결 상태에 따라 표시됩니다.

## 기능

- 연결된 외장 저장소에서 폴더 선택 시작, 승인했던 폴더 재연결 및 다른 폴더 선택
- 하위 폴더 JPEG 읽기와 원본 비율 미리보기
- EXIF 촬영일별 그룹 선택, 촬영일 없음 별도 그룹, 장소는 날짜 아래 보조 안내
- 사진 밖의 버튼·앨범에서 별로 / 좋음 / 아주 좋음 평가 (스와이프 평가 없음)
- 두 손가락 핀치 1~3배 확대, 모든 손가락을 떼면 원복, 확대 시 고해상도 미리보기
- 같은 폴더 재선택 시 평가 복원
- 평가 결과에서 아주 좋음만 / 좋음까지 포함 선택
- 원본 JPEG를 갤러리의 Photo Pick 앨범(Pictures/Photo Pick)에 저장
- 저장 진행률·중단·부분 실패 안내, 앱에서 이미 저장한 원본 재저장 방지

사진을 삭제하거나 다시 평가해도 SD카드 원본은 수정하지 않습니다. 앨범 저장은 JPEG 바이트를 그대로 복사하여 메타데이터를 유지합니다. 미리보기만 축소합니다. 예시 사진은 체험 흐름이며 실제 저장 기능 검증은 SD카드 사진으로 해야 합니다.

## 빌드

Android Studio에서 이 폴더를 열거나, JDK 17과 Android SDK 35 환경에서 실행합니다.

```
./gradlew assembleDebug lintDebug
```

GitHub Actions의 Build Android APK 작업에서도 빌드합니다. 성공한 실행의 PhotoPick-debug-apk 아티팩트에 설치용 app-debug.apk가 있습니다. 배포 파일은 테스트용 debug APK이며 Play Store 배포용 서명은 포함하지 않습니다.

## 실제 기기 확인

1. APK를 휴대폰에 설치하고 SD카드 리더기를 연결합니다.
2. 앱에서 SD카드 사진 폴더를 선택합니다. 시스템 선택기가 SD카드 자체 루트를 허용하지 않으면 DCIM 등 하위 폴더를 선택합니다.
3. 세 등급으로 평가하고 저장 범위를 바꾸어 갤러리 Photo Pick 앨범의 원본 사진을 확인합니다.
4. 같은 사진 재저장, 저장 중 취소, SD카드 분리, 저장 공간 부족을 확인합니다.
5. 앱을 종료한 뒤 같은 폴더를 선택하여 평가 복원을 확인합니다.

빌드·브라우저 어댑터 검증과 실기기 검증은 별도입니다. 갤러리 앱에 따른 앨범 표시, 실제 리더기 호환성, 대량 사진 성능은 기기에서 확인해야 합니다.


### 0.2.1 선택 흐름
- 메인 SD카드 연결 버튼은 매번 시스템 폴더 선택창을 엽니다. 아래 이어서 평가는 기존 세션과 승인 폴더로 재연결합니다.
- 로딩 중 사진 목록을 먼저 확인하고 전체 장수가 확정되면 불러온 장수/전체 장수와 사용 팁을 표시합니다.
- 사진그룹 선택 화면은 전체 해제로 시작합니다. 촬영일별 그룹, 왼쪽 체크박스, 평가(완료/전체장) 표시 및 전체 선택/해제 토글을 제공합니다.
- 사진그룹 선택에서 메인으로 돌아갈 때 확인창을 표시하며 평가 기록은 보존합니다.
